# PhoenixSoulfire

A powerful browser-based tool to detect AI-generated text and protect human judgment.

## What is PhoenixSoulfire?

PhoenixSoulfire helps you stay sharp when working with AI outputs. 

Paste any text and get:
- An AI likelihood score based on 40+ detection rules
- Key signals that indicate machine-generated content
- Sharp judgment questions to help you keep your own thinking

No API keys. No signups. Runs entirely in your browser.

## Features

- 40+ rule-based detection signals
- Clean, modern interface
- Instant analysis
- Judgment questions to keep you sharp
- Completely private (everything runs locally)

## How to use

1. Open `index.html` in your browser
2. Paste the text you want to analyze
3. Click "Analyze Text"
4. Review the results and judgment questions
